# نظام الإجازات — كلية الهندسة المعمارية

موقع ثابت (HTML/CSS/JS بدون build) + Firebase (Auth + Firestore) مع تزامن لحظي.

## الأدوار
- **سوبر أدمن (superadmin):** كل الصلاحيات — إنشاء الحسابات وتفعيلها وإيقافها، تعديل قوانين الاحتساب، النسخ الاحتياطي.
- **مسؤول الإجازات (admin):** يضيف المنتسبين، يقدم طلب إجازة، يحذف طلب غير موافق عليه، ويقدم طلب سحب لإجازة موافق عليها.
- **المعاون الإداري (assistant):** يستلم الطلبات وطلبات السحب لحظياً مع إشعار، ويوافق أو يرفض.
- **حساب النسخ الاحتياطي (backup):** قراءة فقط للنسخة الليلية، ما يدخل للواجهة.
الصلاحيات مفروضة من قواعد Firestore على السيرفر، مو بس مخفية بالواجهة.

## القوانين (من الإعدادات — سوبر أدمن)
- **الموظف — قانون الخدمة المدنية 24/1960:** 3 أيام شهرياً (م43: يوم عن كل 10 أيام)، تتراكم لحد 180 يوم، أقصى 120 يوم براتب بالمرة، وعند عدم كفاية الرصيد بدون راتب (لحد 60 يوم — م43/4).
- **التدريسي — قانون الخدمة الجامعية 23/2008:** 15 يوم لكل سنة دراسية وتتراكم، ولا يمنح أكثر من 30 يوم براتب خلال السنة الدراسية (م10/1). العطلة الصيفية والتفرغ العلمي لا تخصم.
- **المرضية (م46):** رصيد مرضي مستقل 30 يوم سنوياً براتب تام، وما زاد بنصف راتب.
- الزمنية: تتحول لأيام حسب ساعات الدوام (عرف إداري — ما لكينا نص صريح).

## السحب والحذف والاستمارات
- الحذف للطلبات غير الموافق عليها (حذف ناعم يبقى بسجل التدقيق).
- الإجازة الموافق عليها تُسحب: طلب سحب ← المعاون يوافق ← يرجع الرصيد وتصير "مسحوبة".
- كل موافقة تطلع استمارة رسمية بصفحة "الاستمارات" قابلة للطباعة A4.

## الإشعارات
- تظهر على الموبايل واللابتوب ما دام الموقع مفتوح (حتى بتبويب بالخلفية): المعاون عند وصول طلب، ومسؤول الإجازات عند قرار المعاون.
- لازم ضغطة "فعّل الإشعارات" أول مرة على كل جهاز. على الآيفون: أضف الموقع للشاشة الرئيسية أولاً.

## التشغيل المحلي
```bash
node .claude/serve.mjs
```
ثم افتح http://localhost:5178 (يتصل بنفس قاعدة البيانات الحقيقية).

## الربط بـ Firebase
1. أنشئ مشروع في console.firebase.google.com (خطة Spark المجانية).
2. Authentication ← فعّل Email/Password.
3. Firestore Database ← أنشئ قاعدة بيانات (Production mode) ← Rules ← الصق محتوى `firestore.rules` ← Publish.
4. Project settings ← Your apps ← Web ← انسخ الإعدادات إلى `js/config.js`.
5. Authentication ← Settings ← Authorized domains ← أضف نطاق GitHub Pages.
6. افتح الموقع: أول مرة يطلب إنشاء حساب مسؤول النظام.
7. من الإعدادات أنشئ حساب المعاون الإداري وحساب النسخ الاحتياطي.

## النسخ الاحتياطي
- مجلد `backup-repo/` يُرفع كمستودع GitHub **خاص** منفصل (لأن مستودع الموقع عام).
- أسرار المستودع: `FIREBASE_API_KEY`, `FIREBASE_PROJECT_ID`, `BACKUP_USERNAME`, `BACKUP_PASSWORD`.
- كل ليلة 00:30 بتوقيت بغداد تنحفظ نسخة كاملة بـ `backups/daily/YYYY-MM-DD.json`.
- إضافة لهذا: سجل حركة الأرصدة بالقاعدة لا يُعدّل ولا يُحذف، والطلبات والمنتسبين ما تنحذف (أرشفة فقط).
