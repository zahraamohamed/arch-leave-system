# نظام الإجازات — كلية الهندسة المعمارية

موقع ثابت (HTML/CSS/JS بدون build) + Firebase (Auth + Firestore) مع تزامن لحظي.

## الأدوار
- **مسؤول النظام (admin):** يضيف المنتسبين وأرصدتهم، يدخل طلب الإجازة، يلغي طلب معلق، يعدل القوانين والحسابات.
- **المعاون الإداري (assistant):** يستلم الطلبات لحظياً في "الطلبات الواردة" ويوافق أو يرفض. الموافقة تخصم من الرصيد تلقائياً.
- **حساب النسخ الاحتياطي (backup):** قراءة فقط، يستخدمه GitHub Action للنسخة اليومية. ما يدخل للواجهة.

## القوانين (قابلة للتعديل من الإعدادات)
- الموظف: 3 أيام تنزل كل شهر وتتراكم.
- التدريسي: 15 يوم بالسنة فقط (تتجدد ببداية كل سنة).
- عند الطلب: إذا الرصيد يكفي ← **براتب**. إذا ما يكفي ← **بدون راتب** (أو اختيارياً: المتوفر براتب والباقي بدون راتب).
- الاستحقاق يُضاف تلقائياً أول ما يفتح أي مستخدم النظام بالشهر الجديد، وكل إضافة تنسجل بحركة الرصيد.
- الجمعة والسبت ما تنحسب ضمن أيام الإجازة (قابل للتغيير).

## التشغيل المحلي
```bash
node .claude/serve.mjs
```
ثم افتح http://localhost:5178 — بدون إعداد Firebase يشتغل بوضع تجريبي (admin/admin123، assistant/assist123).

## الربط بـ Firebase
1. أنشئ مشروع في console.firebase.google.com (خطة Spark المجانية).
2. Authentication ← فعّل Email/Password.
3. Firestore Database ← أنشئ قاعدة بيانات (Production mode) ← Rules ← الصق محتوى `firestore.rules` ← Publish.
4. Project settings ← Your apps ← Web ← انسخ الإعدادات إلى `js/config.js`.
5. Authentication ← Settings ← Authorized domains ← أضف نطاق GitHub Pages.
6. افتح الموقع: أول مرة يطلب إنشاء حساب مسؤول النظام.
7. من الإعدادات أنشئ حساب المعاون الإداري وحساب النسخ الاحتياطي.

## النسخ الاحتياطي
- مجلد `backup-repo/` يُرفع كمستودع GitHub **خاص** منفصل (لأن مستودع الموقع عام).
- أسرار المستودع: `FIREBASE_API_KEY`, `FIREBASE_PROJECT_ID`, `BACKUP_USERNAME`, `BACKUP_PASSWORD`.
- كل ليلة 00:30 بتوقيت بغداد تنحفظ نسخة كاملة بـ `backups/daily/YYYY-MM-DD.json`.
- إضافة لهذا: سجل حركة الأرصدة بالقاعدة لا يُعدّل ولا يُحذف، والطلبات والمنتسبين ما تنحذف (أرشفة فقط).
